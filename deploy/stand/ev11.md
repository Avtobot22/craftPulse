# EV-11. Клавиатурный проход входа, области, структуры и ролей

Проверка охватывает часть основного пути из [NFR-016 и NFR-017](../../docs/technical-specification/technical-specification.md#83-демонстрационный-mvp-и-общий-минимум), которую реализует MVP-11.

## Подготовка

Используй отдельную установку с тестовыми учётными записями, исходный снимок и браузеры из [браузерной приёмки AC-01](ac01-browser.md). В установке должен быть готов протокол диагностики. Сверь SHA выпуска по `/version`. Перед каждой комбинацией, а также между ручным и автоматическим проходами восстанови исходный снимок. Сценарии активируют организацию, меняют структуру и роли, завершают сессии и блокируют тестового пользователя.

Задай параметры `AC01_*` по инструкции AC-01, включая полный номер комплектного браузера и новый каталог свидетельств вне checkout с правами 0700. Размер окна задаёт `AC01_PROFILE`. Автоматический проход запускается отдельно от AC-01:

```sh
npm --prefix frontend/e2e test -- --config ev11.config.mjs
```

При запуске зафиксируй для каждой комбинации версию браузера, ОС и SHA выпуска. Для ручного прохода выставь масштаб 100% и проверь размер области просмотра в CSS px.

| Профиль       | Область просмотра |
| ------------- | ----------------- |
| chromium-1280 | 1280 × 800        |
| chromium-1920 | 1920 × 1080       |
| firefox-1280  | 1280 × 800        |
| firefox-1920  | 1920 × 1080       |

## Ручной проход

Заполни отдельную копию таблицы для каждой комбинации. На каждом шаге проверь видимое кольцо фокуса, соответствие порядка Tab порядку чтения, отсутствие перекрытия верхней строкой и обрезки элементов. Страница целиком не должна прокручиваться по горизонтали. Повтори ошибки и состояния в оттенках серого. Текст и иконка должны передавать смысл состояния. Прямые ссылки открывай через адресную строку. Внутри экрана используй Tab, Shift+Tab, Enter, Space и Escape, а для выбора в нативных списках применяй стрелки.

| Экран                 | Действия и ожидаемый результат                                                                                                                                                                                                                                                                                                                                                                  | Исход |
| --------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----- |
| UI-02                 | Открой ссылку своей организации. Дойди до кнопки GitLab, войди тестовой записью без мыши. После возврата фокус на заголовке.                                                                                                                                                                                                                                                                    |       |
| UI-03                 | Войди посторонней записью в ещё не настроенную организацию. У отказа есть заголовок, причина и иконка. Вернись к началу клавишей Space.                                                                                                                                                                                                                                                         |       |
| UI-06                 | Войди первым администратором второй организации. Проверь текст результата и перейди в структуру по ссылке.                                                                                                                                                                                                                                                                                      |       |
| UI-01                 | В первой организации проверь порядок «К содержимому», команда, проект и остальные элементы верхней строки. Выбери команду и проект, проверь сохранение фокуса на списке. Пройди навигацию в обе стороны и выполни выход.                                                                                                                                                                        |       |
| UI-04                 | Открой прямую ссылку на проект другой организации. У отказа есть текст и иконка. Фокус на заголовке. ### Состояния без цвета

Для каждого состояния запиши экран, способ воспроизведения и исход. Для неприменимого варианта укажи причину. Например, структура организации и назначения ролей не публикуют частичный аналитический результат S-05.

| Состояние | Что проверить                                                                                          | Исход |
| --------- | ------------------------------------------------------------------------------------------------------ | ----- |
| S-01      | При медленном ответе видно сообщение о загрузке и индикатор.                                           |       |
| S-02      | Загруженные структура, список пользователей и протокол содержат текстовые подписи статусов.            |       |
| S-03      | У пустого списка или отсутствующего протокола есть понятная причина.                                   |       |
| S-04      | При сбое загрузки видны причина и действие повтора. После восстановления повтор доступен с клавиатуры. |       |
| S-05      | На применимом экране частичный результат обозначен текстом и иконкой, указан охват.                    |       |
| S-06      | Неизвестный исход проверки установки отличается от успешного и неуспешного.                            |       |
| S-07      | На применимом экране устаревший снимок имеет дату, текущая ошибка показана отдельно.                   |       |
| S-09      | После записи UI-07 и UI-08 показывают подтверждение, а протокол указывает исход проверки.              |       |

## Свидетельства

`run.json` содержит SHA выпуска, фактические браузер и ОС, окно и исходы
именованных шагов автоматизации. Для ручного прохода запиши шаги фокуса и
сними ошибки форм, отказы, конфликт и исходы протокола. Приостанови запись
на время ввода учётных данных и переходов через OAuth. Проверь, что в записях
и снимках отсутствуют пароли, коды OAuth и сессионные данные.

Отчёты, заполненные чек-листы, записи и снимки сохраняй вне рабочей копии.
