# Конфиденциальность тестовой интеграции craftPulse

Действует с 13.11.2026.

craftPulse - тестовый проект аналитики разработки. Интеграция Jira Cloud
и Confluence Cloud используется участниками тестового стенда, которым
администратор предоставил доступ.

## Какие сведения используются

При разрешённом чтении интеграция получает сведения о проектах, задачах,
пространствах, страницах, их содержимом и истории. Эти сведения могут содержать
идентификаторы аккаунтов, имена авторов, исполнителей и редакторов, а также
доступные по API адреса электронной почты.

Сведения нужны для проверки интеграции, сопоставления учётных записей,
расчёта показателей и проверки доступа. Пользовательское разрешение OAuth
запрашивается только на чтение. Оно ограничено правами самого пользователя.

## Хранение и доступ

Рабочие данные находятся в тестовом контуре craftPulse и локальных инструментах
оператора. Организационные сведения о тестовых аккаунтах могут сохраняться
в закрытом командном хранилище. К этим данным имеют доступ участники команды,
которым они нужны для настройки и проверки стенда.

Секреты приложения и служебные API-токены хранятся отдельно от публичного кода
в зашифрованных пакетах. Пользовательские OAuth-токены предназначены для
серверной части; их нельзя помещать в клиентский код, журналы или публичные
обсуждения.

Обработчик авторизации стенда хранит зашифрованные OAuth-токены, account ID
и служебные сроки. Имена, email, аватары и содержимое источников он не сохраняет.
Он передаёт Atlassian account ID и время получения данных через Personal Data
Reporting API. Период отчёта определяется Atlassian; по умолчанию это семь суток.
При требовании удалить или обновить данные обработчик удаляет запись аккаунта
вместе с токенами. Для продолжения работы после обновления нужен новый вход.

## Отключение и удаление

Пользователь может отозвать разрешение в настройках подключённых приложений
Atlassian. Отзыв прекращает разрешённый этим токеном доступ. При отказе
обновления токена обработчик авторизации удаляет свою запись аккаунта.
Организационные записи командного хранилища удаляются отдельно по обращению
к оператору.

Рабочие копии хранятся до удаления оператором. Сохранённые версии могут
оставаться в истории и резервных копиях командного хранилища. По вопросам
доступа и удаления обратитесь к администратору тестового сайта через контакт,
указанный на странице приложения.

Общие вопросы можно направить через
[репозиторий craftPulse](https://github.com/Avtobot22/craftPulse/issues).
Не размещайте там токены, пароли, содержимое закрытых источников или
персональные данные.
