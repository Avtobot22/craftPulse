# Функции, на которые ЦА скажет «да»

Список собран из десяти интервью и сравнения с конкурентами. Для каждой функции указано, кто из собеседников о ней просил и чем она отличает нас от конкурентов. ID стабильные: на них можно ссылаться в задачах и промптах.

Приоритеты: **must** - без этого человек не купит, **should** - сильно усиливает решение, **could** - следующая очередь.
