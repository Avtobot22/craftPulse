## Как пользоваться документацией

Начните с [видения](../product/vision.md): оно описывает подключение, ежедневную работу и ход разработки. [Метрики](../product/metrics.md) объясняют расчёты и переходят к полным каталогам шести блоков. [Коннекторы](../product/connectors.md) задают источники и capabilities; [функции](features.md) - действия пользователя и проверку результата.
